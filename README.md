Motio is a lightweight program that adjusts your camera to track your face using MediaPipe's Blaze facial recognition model.

## Usage

> NOTE: In order to use Motio, you must have OBS Studio installed. Otherwise, the virtual camera output won't work. Additionally, you cannot use the OBS Virtual Camera at the same time as Motio, since they both use the same output device.

### Settings
Once you open Motio, you can configure the following settings in the side panel:
  **Camera:** Select the camera input device
  **Face Tracking:** Toggle the face tracking and adjustment
  **Framing Margin:** How "far away" your face is from the camera
  **Pan Smoothing:** How slow the camera should move

You can reset your settings to their defaults via the button at the bottom.

### Using the virtual camera

Once you've configured your settings to your liking, you can use Motio's output by simply selecting the "OBS Virtual Camera" device as input in whatever program you want to use it for.
